\subsection{Summary and Thesis Positioning}

Prior work provides strong single-layer techniques,
but cross-layer comparability remains limited.
This thesis contributes a unified security-layer perspective:
Layer I for runtime invariants,
Layer II for control-flow integrity,
Layer III for auditing LLM-generated code artifacts,
and Layer IV for search- and documentation-level poisoning risk in coding agents.

This positioning is intended to support more coherent analysis and clearer engineering 
decisions in next-generation web systems.
