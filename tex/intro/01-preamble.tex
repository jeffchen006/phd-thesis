\section{Preamble}

Next-generation web systems increasingly combine decentralized execution, compositional smart contracts, and AI-assisted software development.
This convergence enables powerful applications, but it also amplifies security risk.
In these systems, vulnerabilities often emerge from interactions across components and abstraction layers, rather than from a single local coding error.

This thesis takes a systems-security perspective on this challenge.
Its central argument is that robust protection requires layered reasoning: one must model execution semantics precisely, enforce runtime policies under realistic constraints, and evaluate risks introduced by modern software-generation pipelines.
