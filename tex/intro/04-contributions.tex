\section{Thesis Contributions}

This thesis makes the following contributions.
\begin{itemize}
    \item \textbf{A layered security framing for next-generation web systems.}
    We formulate security as interacting layers spanning execution semantics,
    runtime enforcement, cross-contract integrity, and model-assisted software risk.

    \item \textbf{A unified formal interface.}
    We provide a consistent notation and modeling interface for states, traces,
    objectives, and policy constraints, enabling direct comparison across
    different technical components.

    \item \textbf{Deployment-oriented technical methods.}
    We develop and analyze methods that preserve technical rigor while
    accounting for practical constraints such as gas overhead, runtime behavior,
    and realistic developer workflows.
\end{itemize}
