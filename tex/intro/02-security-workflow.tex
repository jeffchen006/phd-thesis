\section{The Workflow of Security-Layer Reasoning}

We structure the technical workflow in three steps.
First, we formalize the execution substrate, with emphasis on EVM state transitions, call behavior, rollback, and gas-sensitive feasibility.
Second, we encode security policies over transaction traces and cross-contract interactions, then evaluate enforceability under deployment constraints.
Third, we extend the analysis boundary to AI-assisted development and model the risk that malicious artifacts enter systems through generated code.

This workflow mirrors how security decisions are made in practice: from low-level execution guarantees, to protocol-level enforcement, to software-supply-chain exposure.
